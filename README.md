# finalPD

程式設計課期末專題製作的第一人稱動作遊戲。開發從 2025 年 11 月 13 日開始，於 2025 年 12 月 8 日結束。本遊戲使用 raylib 負責渲染與輸入處理，並用 Bullet 進行碰撞偵測。

## 操作說明 (Controls)
- 移動：W A S D
- 視角/瞄準：滑鼠
- 跳躍：Space (空白鍵)
- 暫停：Esc
## 素材與致謝 (Assets & Credits)
- 很多功能用了 raylib
- 碰撞處理使用 Bullet
- 以及其他在此未列出的資源  

---

First person action game built for programming design's final project. Development started on November 13, 2025, and ended on December 8, 2025. The game runs on **raylib** for rendering/input and **Bullet** for collision.

## Controls
- Move: `W A S D`
- Look/aim: Mouse
- Jump: `Space`
- Pause: `Esc`

## Assets & Credits
- Uses raylib for most things
- Physics and collision via Bullet
